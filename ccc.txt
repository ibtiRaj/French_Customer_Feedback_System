🧠 STEP 1 — Install + Load Tokenizer
1. Install required libraries (if not already done)
pip install transformers datasets torch
2. Load CamemBERT tokenizer
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("camembert-base")
📌 Important concept (don’t skip this)

Transformers do NOT work with raw text.

They need:

token IDs
attention masks
fixed sequence length

So we convert:

text → tokens → numbers → tensors

🔄 STEP 2 — Create a proper dataset format

We must convert your data like this:

Input:
review (text)
label (0/1)
Output:
input_ids
attention_mask
labels
3. Tokenization function
def tokenize_function(example):
    return tokenizer(
        example["review"],
        padding="max_length",
        truncation=True,
        max_length=256
    )
4. Apply to dataset

We convert your Hugging Face dataset directly:

from datasets import load_dataset

dataset = load_dataset("allocine")

tokenized_train = dataset["train"].map(tokenize_function, batched=True)
tokenized_val = dataset["validation"].map(tokenize_function, batched=True)
5. Format for PyTorch
tokenized_train.set_format("torch", columns=["input_ids", "attention_mask", "label"])
tokenized_val.set_format("torch", columns=["input_ids", "attention_mask", "label"])
🧠 What you just achieved

You now have:

✔ Clean tokenized dataset
✔ Ready for neural network
✔ Compatible with CamemBERT

🚨 Common mistakes to avoid

Do NOT:

use TF-IDF here
clean text too aggressively
forget truncation (important!)
use raw strings in training
